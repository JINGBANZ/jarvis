# Third-Party Notices

The distributed app carries third-party code three ways: statically linked inside
`Sources/CJarvisAEC/lib/libjarvis-aec.a`, embedded as `Sparkle.framework` at `Contents/Frameworks/`,
and shipped as trained model weights in `Contents/Resources/Jarvis_JarvisApp.bundle`. All three
require these notices to accompany binary distributions.

`Sources/CJarvisAEC/lib/libjarvis-aec.a` is a prebuilt static library (regenerated by
`scripts/build-aec.sh`) that statically links the following third-party components into the app.
Their licenses require that these notices accompany binary distributions. The license texts reproduced
below are the authoritative attribution for the committed `.a`. (`scripts/build-aec.sh` also writes the
exact upstream `LICENSE`/`COPYING`/`AUTHORS` files into a local, git-ignored
`Sources/CJarvisAEC/third_party/` when you rebuild, for cross-checking against the pinned versions —
those copies are not committed.)
