What do I need to run Jarvis?+

An Apple silicon Mac running macOS 14.2 or later. Download the app, move it to Applications, and configure your providers in Settings. macOS will ask for the capture permissions Jarvis needs.

Do I need an API key?+

You configure the services Jarvis uses in Settings → Connections. Depending on your choices, you’ll need provider API keys or a supported subscription sign-in. Provider usage may cost extra. The Settings guide explains the available connections.

Does “voice-only” mean spoken replies?+

You speak; Jarvis replies on screen. Hints appear in a private overlay so you can stay in the conversation. There’s no chat composer or typed-prompt step.

What happens to my conversation data?+

Selected providers receive the audio, text, or screenshots their role needs. Raw audio and the rolling live transcript aren’t archived locally, but Jarvis keeps bounded, owner-only session records, including finalized speech and viewed screenshots. OpenAI coaching requests currently enable server-side storage for debugging. Read the privacy and security details.
