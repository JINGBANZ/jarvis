# Proactive hint demo

Follow the repository instructions. This directory is a HyperFrames general-video project; use the official HyperFrames skills when authoring or reviewing it.

- `BRIEF.md` defines the story and review scope; `frame.md` defines the visual direction.
- Keep one paused, deterministic GSAP timeline registered as `proactive-hint`.
- Use pinned dependencies and the local GSAP asset prepared by `npm ci`.
- Run `npm run check` and inspect key-frame snapshots after scene changes.
- Keep a managed preview running for local review. Produce a final video when requested.
- Keep generated assets, browser state, dependencies, snapshots, and video files out of Git.
