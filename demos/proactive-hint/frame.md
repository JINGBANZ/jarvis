# Visual frame

Mimic a macOS desktop with wallpaper, a menu bar, and a Dock. Place a two-person Zoom Workplace meeting on the left, a separate Visual Studio Code editor in the middle, and a compact Jarvis overlay at the right edge. The overlay may cover the editor's empty right margin, but it must not hide the code or meeting. Remove the presentation headline and oversized app branding.

Canvas: 1920 × 1080, 30 fps, ten seconds. Keep the desktop stable; the hint is the focal event. Zoom uses cameras-off participant avatars, name labels, green speaking outlines, and recognizable meeting controls. Film captions sit above the Dock.

Typography: system-ui for desktop and app chrome, ui-monospace for code. Menu bar 17 px, window titles 17 px, code 21 px, hint 25 px, dialogue 27 px. Small type supports realistic app controls and metadata. Use weights 400, 500, and 600.

Palette: wallpaper #172e47, #23334f, #455c73, #30566b, #152d42; translucent wallpaper shapes use rgb(118,158,163), rgb(61,105,126), rgb(149,176,170), and rgb(30,72,94). Desktop chrome uses rgb(17,28,43), rgb(213,225,235), #e8e9ed, #f5f5f5, and #fff. Window and meeting surfaces #292a2d, #151619, #202124, #1c1d20; window text #d2d3d6; Zoom accents #245cc0, #42615b, #69c877, #bd3b43. Editor surfaces #1e1e1e, #323233, #333333, #252526, #37373d; editor text #c9cbd0, #c9b88d, #d4d4d4, #b5becb, #a1a1a1; syntax #c586c0, #dcdcaa, #b5cea8; status #005b94. Overlay #1a1a1a, #b8b8b8. Film caption background rgb(18,23,29). Dock icons #6bbcf5, #dcebf7, #21395b, #4fa6df, #007acc, #e5ece5, #25352e, #59685e. Traffic lights #ff6058, #febc2e, #28c840. Shadows use translucent black.

Use 12 px corners for app windows and Jarvis, 5 px for meeting tiles, 20 px for the Dock, 12 px for Dock icons and film captions, and 3–5 px for minor controls. Windows and Jarvis have soft, layered shadows. Keep motion quiet: a short desktop entrance, speaking outlines, a loop highlight, the proactive hint typing, and the revised solution. The hint stays visible through the end.

The scene is silent. Do not add a shortcut, manual hint, notification sound, focus change, camera push, or promotional heading.
