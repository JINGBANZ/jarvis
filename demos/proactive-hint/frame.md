# Visual frame

A warm, calm desktop with a clearly readable coding conversation. Use native system typography and a restrained green accent. The single Jarvis hint is the focal event.

Canvas: 1920 × 1080, 30 fps, ten seconds. Keep the headline above the desktop and the dialogue below it. A subtle push toward the code and hint begins when Jarvis appears.

Typography: system-ui for UI and dialogue, ui-monospace for code. Headline 72 px, dialogue 34 px, code 26 px, hint 29 px. Small text is reserved for supporting window chrome and metadata. Use weights 400, 500, 600, and 700.

Palette: warm canvas #eeeae2; paper #faf8f3; mint #e5ece5; participant card #d3ddd1; ink #25352e; accent #37694d; muted ink #59685e; editor #171f1c; editor chrome #243029; muted editor #8ca295; code #d8e2d9; bright text #f1f5ef; syntax #b7d7a9, #d6c1a2, #aecac5; overlay #1a1a1a; overlay text #f5f5f5 and #b8b8b8. Native traffic lights use #ff6058, #febc2e, and #28c840.

Use 12 px panel corners and soft layered shadows. The desktop window uses 18 px corners. Keep motion brief and purposeful: one entrance, a speaking outline, a soft loop highlight, the hint appearing and typing, then the revised code. The hint stays visible through the end.

The scene is silent. Do not add a shortcut, manual interaction, notification sound, neon glow, or unrelated promotional card.
