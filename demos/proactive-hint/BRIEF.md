# Jarvis proactive hint scene

Show how Jarvis offers a useful, quiet hint during a coding conversation. The user continues talking while a small overlay suggests a better approach.

## Agreed scope

- Build a controlled HTML mock with HyperFrames for visual review.
- Focus on a proactive hint; omit shortcuts and manual requests.
- Use synthetic content only. No screen recording, real call, or provider requests.
- First pass is silent. Dialogue captions are part of the film, not Jarvis UI.
- Deliver a playable local preview before producing a final video.

## Story

An interviewer asks whether the candidate can improve a Two Sum solution. The candidate is checking every pair. At 4.5 seconds, Jarvis quietly suggests looking up the complement in a hash map. The candidate describes the idea and begins revising the code.

English, landscape format, and this coding example carry forward the proposed first scene. Review can change the example, copy, timing, or layout.

## Visual truth

The surrounding call and editor are illustrative. The Jarvis overlay follows the app's compact dark panel, Jarvis header, timestamp, and hint hierarchy. It appears without stealing focus or announcing itself.

## Completion criteria

The ten-second timeline plays and seeks deterministically, key frames are visually inspected, HyperFrames check passes, the repository Gate passes, and a persistent local preview is available for review.
